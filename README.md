🚢 Titanic Data Cleaning & Exploratory Data Analysis (EDA)

📌 Project Overview

This project performs data cleaning and exploratory data analysis (EDA) on the Titanic Dataset.

The goal is to analyze passenger data, identify patterns, and understand factors affecting survival.

🎯 Objectives

Clean and preprocess raw data

Handle missing values

Convert categorical data into numerical form

Perform exploratory data analysis

Identify trends and relationships between variables

Embarked location
