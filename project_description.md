🚢 Titanic Data Analysis using Python
📌 Project Overview

This project focuses on analyzing the Titanic dataset using Python to uncover meaningful patterns and insights. It involves data cleaning, exploration, and visualization to understand the factors that influenced passenger survival.

🎯 Objective
Perform Exploratory Data Analysis (EDA)
Identify key factors affecting survival.
Visualize trends and patterns in the dataset
📊 Dataset Information
Dataset: Titanic Dataset
Source: Kaggle
Includes features such as:
Age
Gender
Passenger Class
Fare
⚙️ Technologies Used
Python
Pandas
NumPy
Matplotlib
🔍 Key Tasks Performed
Data Cleaning
Handling Missing Values
Data Visualization
Exploratory Data Analysis (EDA)
📈 Insights Gained
Female passengers had a higher survival rate
First-class passengers were more likely to survive
Age and fare showed influence on survival probability
